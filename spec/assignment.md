# 單人專題審核說明文件｜前後端整合主題電商平台 - 2026 企業專題班

## 一、 專案目標與說明

本題目用來確認學員能 **獨立** 完成一個前後端分離、實際串接的全端專案。
學員可自訂電商主題（如選物店、oo 電商等題目）完成前後端開發、資料庫設計與雲端部署，並進行實際串接。
本題目僅描述功能需求，API 設計、資料庫結構、頁面細節與元件拆分皆可自行規劃。

## 二、 技術限制

**【後端】**

- 使用 Node.js 與 Express 開發。
- 資料庫不限制，可自行選擇合適的資料庫與 ORM 或 Query Builder。
- 專案需落實 MVC 架構，路由、控制邏輯與資料模型的職責必須分開。
- **機密資料**（如環境變數、連線字串）絕對不可出現在程式碼或版本紀錄中。

**【前端】**

- 使用 Vite 建立專案，並使用 **Vue 3（Composition API）**。
- 搭配任一 CSS 框架（如 Tailwind CSS 或 Bootstrap 5）。
- 元件需合理拆分，並使用正確的 HTML5 語意標籤。
- **注意：** 不可使用假資料或 JSON Server，所有資料必須來自你自己開發的後端 API。

**【部署與架構】**

- 前端與後端請放置於獨立的 GitHub Repo，且皆須**獨立部署至雲端環境**並完成實際串接：
    - **前端**：需部署並提供可公開連線的「網站網址（URL）」，供審核者直接操作與測試介面。
    - **後端**：需部署並提供可公開呼叫的「API 伺服器網址（API Base URL）」，供前端串接，並允許審核者透過 Postman 等工具測試 API。

## 三、 功能需求

### 1. 後端功能需求

- **會員系統：**
    - 使用者可註冊與登入。
    - 密碼不可明文儲存，登入成功後以 JWT 發行 Token。
    - 系統需區分「一般會員」與「管理員」，一般使用者絕對不能透過任何方式將自己升級為管理員
    - 管理員帳號的產生方式請自行規劃，並於提交時說明。
- **商品功能：**
    - 所有人皆可瀏覽商品列表與單一商品內容。
    - 列表需支援分頁、分類篩選與關鍵字搜尋。
    - **【管理員專屬】** 可新增、編輯、刪除商品（僅要求完成 API，不強制製作前台的後台管理頁面）。
- **購物車：**
    - 登入的會員可將商品加入購物車、調整數量、移除商品，並查看購物車內容。
    - 需自行處理各種邊界情況（如：重複加入、商品不存在、數量不合理等）。

### 2. 前端功能需求

- **頁面與排版：**
    - 至少需包含：首頁、商品列表頁、登入與註冊頁、購物車介面（可用 Offcanvas、Modal 或獨立頁面）。
    - 所有頁面皆須支援 RWD，在手機與桌機上都有合理的版面。
- **商品列表：**
    - 資料從後端 API 取得，需能依分類篩選、以關鍵字搜尋，並支援分頁或其他合理的分批載入方式。
    - 資料載入中、查無結果、API 錯誤時，畫面都要有適當的提示。
- **會員與登入狀態：**
    - 使用者可在前端註冊與登入。登入狀態在重新整理頁面後仍需維持，並提供登出功能。
    - 未登入的使用者嘗試加入購物車時，需有合理的處理方式或引導。
- **購物車與狀態管理（重點檢核）：**
    - 加入、增減數量、移除商品後，**必須與後端資料同步**。
    - 加入購物車時需給予使用者明確的操作回饋。

## 五、 評分標準（總分 100 分）

 **注意：** 前端網址、後端網址任一無法連線，或 Repo 無法存取、缺少 API 文件者，**不予評分**。

- **後端（40%）**
    - 功能完整性（15%）：會員、商品、購物車等 API 是否完整且正常運作。
    - 架構與規範（10%）：MVC 分層、非同步流程是否正確。
    - 資料庫設計（10%）：資料表結構與關聯是否合理，是否有確實的欄位驗證與約束。
    - 身分驗證（5%）：密碼加密、JWT 機制與管理員權限控管是否正確。
- **前端（40%）**
    - 畫面與 RWD（20%）：各斷點不跑版，導覽列與商品排列在行動版與桌機版都合理。
    - 元件化與語意（10%）：元件拆分是否有效，語意標籤是否使用正確。
    - 互動與細節（10%）：Hover 效果、操作回饋、載入狀態的呈現、圖片自適應。
- **前後端整合（20%）**
    - 串接正確性（5%）：資料是否確實來自自己的後端。
    - 登入流程（5%）：Token 的保存與使用、登入狀態的維持與登出是否完整。
    - 資料同步（5%）：購物車操作與後端資料是否一致。
    - 部署環境（5%）：整體流程在部署環境中是否能完整運作。

**達標條件**：

- 總分達 70 分，且後端與前端兩部分各自至少達 24 分。
